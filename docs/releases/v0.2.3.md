# whyline-relay 0.2.3

One wording fix to the built-in implementer prompt, found by actually running a real headless agent through the relay and watching it fail in a new way.

## Fixed

- **The implementer's default prompt now forbids running anything in the background.** Measured against Google's Antigravity CLI (`agy`), configured as a generic agent: asked to "run the project's tests," it started something in the background, reported its turn a success, and the CLI process exited before that work finished — no handoff, no commit, the background task silently killed on exit. The built-in `implement.md` now says explicitly: run every command to completion and read its result before finishing the turn, never in the background, never ending the turn while something started is still running.
- A real side-by-side comparison ruled out the alternative fix (telling the *task* not to run any test command instead): the prompt-level fix used roughly half the tokens and let the agent actually run the real tests, instead of only reading files back to "verify" without executing anything.
- This is Codex- and Claude-safe too — neither has been observed doing this, but the instruction costs them nothing and closes the same class of risk for any future agent.

## Also fixed: a factual error in the published 0.2.2 release notes

The 0.2.2 release notes (here and on GitHub) said "260 tests (237 before)". The real number, verified by checking out the v0.2.1 and v0.2.2 tags and running the suite at each, is **311 tests (237 before)**. Both this repository's `docs/releases/v0.2.2.md` and the live GitHub Release have been corrected. 0.1.0's and 0.2.0's published counts (140 and 196) were independently re-checked and are correct.

## Who this affects

Only repositories using the **default** `implement.md` (the common case; `init` writes it, and it's untouched unless you edited it yourself). If you've customized `.whyline/relay/prompts/implement.md`, this release changes nothing for you — add the line yourself if you want it, or run `init --overwrite` to get the new default (which discards your edits, as always).

## Upgrading from 0.2.2

`uv tool upgrade whyline-relay`. Existing repositories with a customized `implement.md` are unaffected. Repositories using the default template will see the new wording starting with the next `whyline-relay init --overwrite`, or immediately if `init` has never been run there.

## How it was checked

- 313 tests (311 before), on Linux and macOS, Python 3.11 and 3.13.
- The old byte-for-byte-against-0.2.1 golden test for the default `IMPLEMENT` prompt was retired (it was only ever meant to prove the 0.2.2 adapter refactor changed nothing, and this release deliberately changes that prompt) and replaced with a golden of the new default plus a direct content check; the equivalent `REVIEW` golden, which is unaffected, still holds.
- The fix itself was validated for real, not just unit-tested: two full relay runs against Antigravity as the implementer, Claude as the reviewer, one with the old wording (which hung on a backgrounded command) and one with the new wording (which completed in one round, correctly running the real tests before handing off).

## Known issues

- Tested on macOS only. Windows is untested.
- Only `codex` and `claude` are built in. Antigravity/`agy` works today only via the generic adapter, documented in the README; it is not a built-in candidate until it can scope its own permissions, report a login status, and name what it denied.
- No phase gate: use one plan file per phase to get a review point.
- An automated review is lighter than a careful human one. Read the branch before merging.
