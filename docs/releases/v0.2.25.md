# whyline-relay 0.2.25

This release adds configurable per-agent brainstorm timeouts.

- Brainstorm setup offers 15 minutes (default), 30, 45, or 60 minutes.
- The selected timeout is explicitly per agent turn, not a whole-run deadline.
- The value applies to research, review, final synthesis, and plan drafting.
- The selection is persisted when a brainstorm is resumed.
- Existing non-interactive relay timeout configuration is unchanged.

Tests: `uv run pytest` — 728 passed.
