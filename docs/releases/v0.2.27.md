# whyline-relay 0.2.27

Making a plan no longer requires running `init` first.

## What's fixed

- Planning in a repository where `whyline relay init` had never run failed at
  the review step: claude stopped with "Settings file not found" and the
  plan was reported as "claude exited without handing off". whyline's
  console offers Plan before Set up, so every new repository hit this. The
  planner now creates the agents' permission files (e.g.
  `.whyline/relay/claude-settings.json`) before it starts, the same way chat
  and brainstorm already did. An existing file is never overwritten, and the
  file is not committed: planning still commits only the plan.

## Recovering a failed draft

The draft that was written before the failure is kept. Open Plan in the
console and choose "Resume draft".

## Upgrading

```bash
uv tool upgrade whyline
```
