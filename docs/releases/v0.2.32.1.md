# whyline-relay 0.2.32.1

Planning finishes cleanly.

## What's changed

- **Finished planning no longer looks like a running relay.** Planner and spec
  draft/review pipelines now release their live marker on success, pause, and
  failure. A long-lived console process can therefore move directly from an
  approved plan into Set up without a false `__plan__` conflict or an active
  Stop button.
- **Planning decisions travel with the approved artifact.** When drafting a
  spec or plan records shared Whyline decisions, those changes are committed
  with the approved document. Other dirty files remain untouched, so the next
  relay preflight starts clean without sweeping unrelated work into the commit.

This maintenance release intentionally keeps `0.2.33` available for the
already-planned timeout work.

## Upgrading

```bash
uv tool upgrade whyline
```
