# whyline-relay 0.2.32

Grok finishes its turns.

## What's changed

- **A cancelled Grok turn is resumed, not abandoned.** Headless Grok (measured
  on 1.0.41) ends its whole turn as `cancelled` when it tries any command or
  web fetch outside its allow list, instead of refusing that one call. This
  was behind the long-standing "cancelled with no files" and "exited without
  handing off" stalls. The relay now continues the same Grok session, up to
  twice, with a note on what it may run, so the work it already did is kept.
  This covers relay tasks and chat and brainstorm turns.
- **Grok is told its limits up front.** The built-in Grok command passes
  `--rules` saying a headless run cannot approve prompts: one plain command
  per call, no shell control flow, subshells or `bash -c`.
- **A wider Grok allow list:** `grep`, `head`, `tail`, `wc`, `diff`, `pwd`,
  `git show`, `git rev-parse`, `pytest`, `.venv/bin/pytest`,
  `.venv/bin/python` and `WebFetch`, so research and brainstorm prompts that
  name a URL work.

A repository with its own `[agents.grok]` table keeps its command; copy the
new flags from the built-in recipe to get them.

## Upgrading

```bash
uv tool upgrade whyline
```
