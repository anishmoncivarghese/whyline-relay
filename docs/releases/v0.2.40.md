# whyline-relay 0.2.40

Fewer needless pauses, clearer status while a run is going, and a way to switch an agent mid-run.

## What's changed

### Fewer needless pauses
- **Adding later tasks no longer stops a paused run.** A commit that only adds or edits tasks after the current one is accepted, together with `.whyline/decisions.md`. The current task and every earlier task must be unchanged. (RLY-1)
- **The test command.** A `test_command` setting tells agents how to run the tests.
  - It is detected for you, for example `uv run pytest -q` when there's a `uv.lock`, or you set it with `whyline relay test-command "<command>"`.
  - Claude is now given headless rules that include it. (RLY-4, RLY-5)
- **A refused test command isn't treated as a blocker.** When an implementer has written the code and only its test run was refused, the task moves on to the tester instead of pausing. A tester's refused test run is still never a pass. (RLY-7)
- **A brief git index lock is waited out.** When another program, such as the whyline console's status poll, briefly holds `.git/index.lock`, the relay retries for about 8 seconds. Its own read-only git calls no longer take the lock. If a commit still fails after a task is approved, the run pauses with the approval kept, and Resume just commits. (RLY-10)

### Clearer status
- **Pause reasons name the refused command**, for example `claude was denied: python -m pytest. Allowed test command: uv run pytest -q.` (RLY-6)
- **`roles status`:**
  - names the agent that actually hit a limit, not the one configured (RLY-2)
  - lists every agent as ready or not, with the reason: not installed, not logged in, or limited until a time (RLY-9)
- **The live-run marker includes the stage and visit count.** The whyline console can show "fixing after review 2" instead of just the task. The echo reads `visit 2` on a revisit. (RLY-11)
- **Testers and reviewers list each problem separately** with `--issue`, when whyline supports it. The implementer gets a numbered list to work through. (RLY-12)

### Agents
- **Usage limits are remembered until they reset.** An agent that hit a 429 or a 402 is skipped in the backup chain until its reset time, instead of being tried again on every turn. A successful turn clears the record. (RLY-8)
- **Generic agents can take a model.** Set `model_flag = ["--model"]` for grok or antigravity, and `model = "…"` works as it does for claude and codex. (RLY-3)
- **`roles switch <role> <agent> [--keep]`** changes a role's agent while the relay runs, from that role's next turn.
  - `roles reset` switches it back.
  - The switch ends when the plan completes, unless `--keep` is given.
  - If the switched agent hits a limit, it fails over through the backup chain as usual. (RLY-13)

## Upgrading

```bash
uv tool upgrade whyline-relay
```
