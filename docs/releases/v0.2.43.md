# whyline-relay 0.2.43

Change an agent's model while the relay runs, keep grok from stopping on coloured git commands, and keep the relay's own run-time files out of your commits.

## What's changed

- **`whyline-relay roles model <agent> <model>`.** It switches an agent's model from its next turn, never the current one, for example `roles model claude opus`. A model belongs to an agent, so the switch applies in every role that agent plays, backups included. The log says "claude now uses opus (switched by you)". `--keep` also saves the model to `config.toml` for later runs, and `--reset` goes back to the configured model. `status` and `roles status` show a switched model, and the turn log and `running.json` record the model each turn used. Tools such as the whyline console call the same `roles.switch_model`. (RLY-18)
- **Grok no longer stops on `git -c color.ui=false …`.** Headless grok ended its whole turn when it ran a git command outside its allow list, and the most common one was a no-colour `git diff`. The agents are now told to run plain `git diff`, `git log`, `git show` and `git status`, and exactly these no-colour forms are allowed for grok, Antigravity and claude: `git -c color.ui=false -c color.diff=false diff`, `log` and `show`. `git -c` in general and `git --no-pager` stay refused, because `-c` can make git run other programs. When a cut-off grok turn is resumed, the resume prompt names the refused command and what to use instead, and the log shows `(refused: <command>)`. (RLY-15)
- **The relay never commits its own run-time files.** A pause pressed during a turn could end up in that task's commit as `.whyline/relay/PAUSE`, and any checkout of that commit would then pause after its next turn. The relay's commit step now always leaves `PAUSE` and `STOP` out. The relay's `.gitignore` lists every file it writes while running: `PAUSE`, `recovery.json`, `agent-limits.json`, `model-overrides.json`, `skipped-tasks.json` and the rest. An older `.gitignore` gets the missing lines added under `# added by whyline-relay` at the next `start` or `resume`, with your own lines kept as they are. If `PAUSE` or `STOP` is already in git, `start` and `resume` print the `git rm --cached` command to fix it. (RLY-17)

## Upgrading

```bash
uv tool upgrade whyline-relay
```

If you use it through whyline:

```bash
uv --no-cache tool upgrade whyline --upgrade-package whyline-relay
```

If your repository's `.whyline/relay/config.toml` has its own `[agents.grok]` command, it overrides the built-in one. Delete that block to use the new built-in command, or add the three no-colour git forms to its allow list.
