# whyline-relay 0.2.42

A safe pause. You can pause a running relay without losing the current agent's work, and Resume carries on with the next turn. This release also fixes two ways a run could get stuck, and runs Antigravity with a narrow allow list for each run.

## What's changed

- **`whyline-relay pause`.** It asks the relay to pause at the next safe point. The current agent finishes its turn and hands off, and the relay pauses before the next agent starts. `whyline-relay resume` then continues with the next turn, and nothing is redone. `pause --cancel` withdraws the request. A pause for any other reason, or a Resume, clears it. (RPZ-1, RPZ-2)
- **Nothing is lost when a turn is cut off.** `pause --now`, `stop` and Ctrl+C still stop the agent at once. Now the relay records which files that turn had changed. On Resume, the next agent is told to continue from those changes rather than start over or discard them. (RPZ-1, RPZ-3)
- **`status` shows the pause.** While the relay waits for the current turn, `status` says it is pausing and for how long. After that, it says `Paused by you at <task>`. For a cut-off turn, it says which agent's turn was cut off. Tools such as the whyline console read the same information through `status.pause_state`. (RPZ-4)
- **Retry stage frees every capped stage.** `resume --retry-stage` now gives one more visit to every stage at its cap, not only the one named in the pause. A draft, test and review loop no longer needs a press per stage. (RPZ-6)
- **A review that mentions "sandbox" is no longer read as a refused command.** Before, a rejection such as "strip the sandbox_workspace_write override" paused the relay as if the agent had been refused a command, and every Resume paused again. The relay now looks only for real refusal phrases, and a rejection that lists issues is sent back as normal. For a run already stuck this way, use `resume --as-rejection`. (RPZ-7)
- **Antigravity runs with its own allow list.** The built-in Antigravity command passes a narrow `--settings` allow list for each run. It allows file reads and edits plus the same commands as the Grok recipe, but no wildcard, no `git push` and no `rm`. It no longer depends on your machine-wide Antigravity settings. When a turn ends because agy refused a tool call, the pause says so. This needs agy 1.4.12 or later; google-antigravity/antigravity-cli#548 is fixed there. (RPZ-8)

## Upgrading

```bash
uv tool upgrade whyline-relay
```

If you use it through whyline:

```bash
uv --no-cache tool upgrade whyline --upgrade-package whyline-relay
```
