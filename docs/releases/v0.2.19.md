# whyline-relay 0.2.19

This release adds the guided setup wizard for configuring and safely starting a relay plan.

## What's new

- `whyline-relay setup` offers an existing plan or the existing planner workflow.
- The wizard assigns implementer, tester, and reviewer roles and writes a three-stage pipeline.
- Generated setup files are committed before the existing `doctor` checks run.
- `FAIL` checks block starting; warnings require explicit confirmation.
- The new command is documented in the README and exposed through the CLI.
