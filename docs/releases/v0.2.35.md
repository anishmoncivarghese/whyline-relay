# whyline-relay 0.2.35

Relay runs can now be left unattended safely, stopped while an agent is in
flight, and resumed after a sandbox-limited stage without losing the task.

## What's changed

- **Unattended synthesis is explicit.** `run_final_synthesis(...,
  unattended=True)` tells the final writer to finish from the recorded evidence
  when no user will be present, while the existing interactive prompt remains
  unchanged. `setup.write_timeout_minutes` persists the run timeout without
  rewriting unrelated relay configuration.
- **Timeouts can be finite or unlimited.** Agent runs accept an optional
  watchdog and a `cancel_event`; chat exposes `NO_LIMIT`, configuration accepts
  `timeout_minutes = 0`, and the CLI accepts `--timeout none`. A saved one-shot
  timeout survives pause and resume without changing the repository default.
- **Stop cancels the active process.** A STOP file now reaches the in-flight
  agent, terminates its process group, records the interruption, and pauses the
  relay cleanly instead of waiting for the provider command to return.
- **Agents run in the task repository.** Built-in and opted-in generic agents
  receive the task checkout as their working directory, including cross-repo
  plan tasks. Their uv caches stay under that workspace so sandboxed commands
  do not depend on a home-directory cache.
- **Sandbox refusals pause as blocked.** A denied command is classified as a
  blocked outcome instead of consuming the stage until its visit cap. Preflight
  warns when a configured role is likely unable to access the task repository.
- **A capped stage can be retried deliberately.** `whyline relay resume
  --retry-stage` lowers only the capped stage's saved visit count by one,
  records the retry, and leaves other stages unchanged.
- **Approved no-change tasks complete.** A configured pipeline's terminal
  approval creates one task-naming empty commit when there is nothing to stage,
  so already-satisfied tasks can be verified and ticked. Legacy two-role runs
  retain their reviewer-commit rule.

## Upgrading

```bash
uv tool upgrade whyline
```
