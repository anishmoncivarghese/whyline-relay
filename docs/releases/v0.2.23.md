# whyline-relay 0.2.23

This release makes brainstorm execution visible and resilient:

- lifecycle start/finish events include elapsed time and classified failures;
- quota, timeout, authentication, permission, missing-agent, and generic failures are distinguished;
- failed research is excluded from review and synthesis, with automatic synthesizer fallback;
- failed reviews restore the shared brainstorm document without sweeping unrelated changes;
- the `/brainstorm` REPL renders an aggregate progress table, and events are serializable for a future TUI.

Tests: `uv run pytest` — 713 passed.
