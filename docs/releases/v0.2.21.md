# whyline-relay 0.2.21

This release replaces the separate one-hop backup settings with one shared
backup chain used across relay, pipeline, chat, and brainstorm workflows.

## What's new

- Configure one ordered `[backup] chain` instead of role-specific backup keys.
- Walk the chain across real agent failures while skipping agents already tried.
- Preserve tried-agent history in active overrides and show it in `roles status`.
- Apply failover consistently to legacy tasks, pipelines, chat, and brainstorm.
- Validate every configured chain agent in `doctor`.
- Keep brainstorm attribution accurate when a chain substitution occurs.
