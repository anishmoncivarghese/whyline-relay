# whyline-relay 0.2.39

Grok permission cancellations now continue the same agent session instead of
pausing Relay with `last output was: "}"`.

## What's changed

- **Prefixed Grok JSON is recognized.** When headless Grok prints a
  `permission required:` diagnostic before its pretty-printed JSON result,
  Relay now reads the trailing object, sees `stopReason: "cancelled"`, and
  recovers its `sessionId`.
- **Existing recovery now runs.** Relay resumes that same Grok session up to
  its existing retry limit and reminds it to use allowed commands. No new
  permission rules or broader shell access are added.
- **The measured failure shape is covered.** A regression test uses the
  diagnostic-plus-multi-line-JSON form that paused `WIN-1` and `PANE-1`.

## Upgrading

```bash
uv tool upgrade whyline-relay
```
