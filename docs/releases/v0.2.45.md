# whyline-relay 0.2.45

Change the turn timeout, the round cap and the backup order while a relay is running, without stopping it.

## What's changed

- **Three settings you can change mid-run.** Until now a change to the timeout, the round cap or the backup order in `config.toml` did nothing until the relay was stopped and started again. Three new commands change the running relay instead. (LRS-1, LRS-2, LRS-3)

  ```bash
  whyline-relay settings timeout 45
  whyline-relay settings rounds 5
  whyline-relay settings backup codex grok
  ```

  - `timeout` takes minutes, from 1 to 1440; `0` means no limit.
  - `rounds` takes 1 to 99. A cap below the round a task is already on is refused.
  - `backup` takes the agents in order. Each must be set up, and each may appear once. With no names it means no backups.
- **The running turn is never touched.** A new timeout applies from the next turn, a new round cap from the next round check, and a new backup order the next time a backup is needed. The turn in progress keeps the timeout it started with, and an agent already standing in for a role finishes its turn.
- **A change lasts for this run unless you add `--keep`.** Without it, `config.toml` is left exactly as it was and the change is dropped when the run ends. With `--keep` the value is also saved to `config.toml` for later runs. When no relay is running, the commands save to `config.toml` and say `Saved for the next run.`
- **See and undo changes.** `whyline-relay settings` prints the three values, and `status` gains a `Settings:` line. A changed value reads `timeout 45m (was 30m, changed by you)`. `whyline-relay settings reset` drops every change, and `settings reset timeout`, `rounds` or `backup` drops one.
- **A relay paused on the round cap can continue.** Raise the cap above the task's round, then run `resume`. Nothing resumes by itself.
- **A backup agent's model can be switched.** `whyline-relay roles model <agent> <model>` works for an agent that is only a backup and holds no role. It applies when that agent next runs.
- **A settings file that can't be read changes nothing.** The relay keeps the configured values and logs one line.

## Upgrading

```bash
uv tool upgrade whyline-relay
```

If you use it through whyline:

```bash
uv --no-cache tool upgrade whyline --upgrade-package whyline-relay
```
