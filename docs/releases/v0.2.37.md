# whyline-relay 0.2.37

`whyline relay status` no longer reports an old pause as current while a
relay is running.

## What's changed

- **Status while running.** The saved pause is only rewritten at the next
  pause or finish, so during a resumed run `status` used to print
  `Running: ...` and, underneath, the previous `Paused ...` reason and a
  `Resume with:` hint. While an agent is running the saved reason is now
  shown as `Last pause` and the Resume hint is left out. A paused relay
  shows exactly what it did before.

## Upgrading

```bash
uv tool upgrade whyline
```
