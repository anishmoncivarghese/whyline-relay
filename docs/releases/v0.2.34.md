# whyline-relay 0.2.34

The backup chain gets an API of its own, and one relay can run a plan that
spans two repositories.

## What's changed

- **Read and write the backup chain on its own.** `setup.read_backup(root)`
  returns `[backup].chain`, and `setup.write_backup(root, chain)` validates the
  names before writing, replaces only the `[backup]` table and commits just
  `config.toml` (`setup: backup chain codex, grok`). `write_roles` now hands
  its chain to `write_backup`, so the two never write two `[backup]` tables.
- **A repository-only preflight.** `preflight.run(root, scope="repository")`
  checks only the repository: git, whyline, the relay config, permission-bypass
  flags, a clean tree and no live relay. It skips plan and login checks, and
  its dirty-tree failure names every changed path. `scope="full"` is unchanged.
- **Resume commits the relay's own decision log.** When `.whyline/decisions.md`
  is the only uncommitted change, which happens when a round pauses after agents
  ran `whyline note`, `whyline relay resume` commits it (`chore: record <task>
  decisions`) instead of failing the clean-tree check. Any other change still
  fails it, and `--allow-dirty` skips this.
- **Four more runtime files are ignored:** `.whyline/relay/auto-run.json`,
  `auto-run.lock`, `chat-active-agents.json` and `recovery.json`, added to
  `.git/info/exclude` in existing repositories too.
- **Tasks in another repository (`relay-repo:`).** A task can name the
  checkout its code lives in. The relay keeps its plan, state, handoffs and
  logs where it started, and moves only that task's git work: the branch, a
  clean-tree check before the task starts, the base commit, the HEAD checks,
  and the task's commit. You no longer switch repositories partway through a
  plan.
- **Agents are told where handoffs go and are never told to `cd`.** Every
  prompt names the relay repository whose `.whyline/active-handoff.json` the
  relay reads, plus the task repository when it differs, with
  `uv run --directory <repo>` and `git -C <repo>` examples. Headless Grok ends
  its whole turn on a command outside its allow list, and `cd` is not on it.

## Upgrading

```bash
uv tool upgrade whyline
```
