# whyline-relay 0.2.36

An agent that runs out of paid credit now hands its role to the backup
instead of pausing the relay.

## What's changed

- **Billing exhaustion counts as a usage limit.** Grok reports an empty
  prepaid balance as `API error (status 402 Payment Required): Grok Build
  usage balance exhausted`. None of the relay's usage-limit phrases matched
  it, so the relay treated the turn as an agent that simply forgot to hand
  off and paused, even with a backup chain configured. "Payment required",
  "balance exhausted", "credit balance is too low", "insufficient credits",
  "insufficient_quota" and "exceeded your current quota" now all trigger the
  switch, for every agent, and the relay prints
  `==> relay: implementer switched from grok to codex (grok hit a usage or rate limit)`.

## Upgrading

```bash
uv tool upgrade whyline
```
