# whyline-relay 0.2.31

Specs, plans from specs, and release tasks that wait for you.

## What's changed

- **Specs.** `whyline_relay.specs` drafts a design spec with the same
  drafter/reviewer pipeline as plans (questions, resume, answers), in its own
  files, so a spec and a plan can be in progress at once. Approving writes
  and commits `docs/specs/<name>.md`.
- **Plans from a spec.** `planner.draft(spec=...)` writes the plan from an
  approved spec. Drafters mark release, publish, tag and deploy tasks with
  `relay-profile: release`.
- **Synthesis revision.** `brainstorm.final_synthesis` and
  `brainstorm.revise_synthesis` read and rework a brainstorm's Final
  Synthesis.
- **The relay commits approved work** in every config format, with
  `<type>: <summary> (<TASK-ID>)`. A reviewer whose prompt still says to
  commit is honoured, so nothing is committed twice.
- **Release tasks wait for you.** With `[roles] release = "human"` (the
  default), a `relay-profile: release` task pauses with its steps as a
  checklist. Run `whyline relay done <TASK>` when finished, or
  `whyline relay skip <TASK>`. With an agent as the release role, the ready
  check warns if its sandbox likely blocks network access and tags.

## Upgrading

uv tool upgrade whyline
