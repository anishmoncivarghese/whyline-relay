# whyline-relay 0.2.20

This release adds the interactive `/brainstorm` workflow to the chat REPL.

## What's new

- `/brainstorm` asks for a topic, participating agents, and the number of review passes.
- Independent brainstorm passes run through the configured agents and are merged into a shared synthesis.
- Review passes critique and improve the synthesis before the final result is shown.
- Brainstorm output is saved in the relay workspace and documented in the README.
- Chat turns accept an explicit commit message so brainstorm artifacts can be committed consistently.
